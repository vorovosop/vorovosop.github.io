VOROVO POS Privacy Policy

Last updated: 23 October 2026

VOROVO POS is a point-of-sale program for Windows, made for the VOROVO shop. This page explains what the program does with the shop's data and with the access it is given to the shop owner's Google Drive.

The shop's data stays on the shop's computer

  • Products, sales, stock, shifts, staff and settings are kept in a database on the shop's own computer.
  • The database is encrypted with the shop's data key. The key is kept on that computer, locked to its Windows account, and on a sheet the owner keeps.
  • VOROVO POS does not send the shop's data to VOROVO or to anyone else. It has no advertising and no tracking, and no data is sold or shared.

Google Drive backups (optional)

The shop owner can connect a Google account in the program's Settings. VOROVO POS then uploads backups of the shop's database to that account's Google Drive.

  • What the program can see: it asks Google only for access to the files it creates itself (the "drive.file" permission). It cannot see, open or change any other file in the Drive.
  • What it stores there: a folder called "VOROVO POS Backups" containing the backup files. Each backup is encrypted with the shop's data key, so it cannot be read without that key.
  • What else it reads: the email address of the connected Google account, only to show the owner which account is connected. It is not stored or sent anywhere.
  • How long backups are kept: backups older than 90 days are removed from the folder, but the newest 10 are always kept.
  • The sign-in: the permission Google gives the program is kept on the shop's computer, locked to its Windows account. It is not sent to VOROVO or to anyone else.

The data received from Google is used only to make, check and remove these backups, and is never transferred to anyone. VOROVO POS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to remove the access

  • In VOROVO POS: Settings, Google Drive, Disconnect.
  • Or in the Google account: myaccount.google.com/permissions, choose VOROVO POS, then remove its access.
  • Backups already in the Drive stay there until the owner deletes the "VOROVO POS Backups" folder.

Changes to this policy

If what the program does with data changes, this page is updated and its date changed.
